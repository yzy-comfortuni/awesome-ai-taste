# Awesome AI Taste

给 AI 查用的设计与写作规则。按任务选一类，先用 1–2 条规则，需要时再读正文，不加载全库。

改稿保留数字、限定、归因与完成状态，不补事实。文体与任务优先；来源的角色、权限和强制流程不自动继承。选读无需安装或运行代码。

- [Ten simple rules for writing a technical book](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1011305) — 技术教学图书的内容试讲与修订，适用于编程及英文技术教程，不是通用软件 README 模板。[正文](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1011305)

  **规则：** 写整章前，先向目标读者试讲核心内容，记录缺失的前置知识，再据反馈调整讲解顺序与例子。[出处](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1011305)

- [EPO Guidelines F-IV, 4.20 — "Comprising" vs "Consisting of"](https://www.epo.org/en/legal/guidelines-epc/2026/f_iv_4_20.html) — 欧洲专利局 2026 年审查指南对开放式与封闭式权利要求用语的解释；限 EPC 审查，不是其他法域的通用写法或授权保证。[正文](https://www.epo.org/en/legal/guidelines-epc/2026/f_iv_4_20.html)

  **规则：** 核对英文权利要求的“comprising”与“consisting of”：允许不妨碍方案工作的附加特征时用前者；只有确实排除附加特征才用后者，并核对原申请依据。[出处](https://www.epo.org/en/legal/guidelines-epc/2026/f_iv_4_20.html)

- [Psychic Distance in Creative Writing](https://www.unr.edu/writing-speaking-center/writing-speaking-resources/psychic-distance-in-creative-writing) — 内华达大学里诺分校写作中心用同一场景的五级改写说明叙事距离；适用于英语小说与叙事散文，五级是分析工具而非固定写作公式。[正文](https://www.unr.edu/writing-speaking-center/writing-speaking-resources/psychic-distance-in-creative-writing)

  **规则：** 修改人物焦点段落时，标出远景交代与人物感官、措辞的切换；若从外部背景突然跳进内心让读者失去定位，就用人物偏好或即时反应作过渡。[出处](https://www.unr.edu/writing-speaking-center/writing-speaking-resources/psychic-distance-in-creative-writing)

- [The Peril of the Poetry Reading: The Page Versus the Performance](https://poets.org/text/peril-poetry-reading-page-versus-performance) — David Groff 讨论纸面诗与朗诵的不同，提醒表演可能遮掩文字问题；限英语纸面诗。[正文](https://poets.org/text/peril-poetry-reading-page-versus-performance)

  **规则：** 对主要供纸面阅读的诗稿，朗读后再让读者静默阅读；标出只能靠朗诵语速和语气才能读顺的诗句，优先修改文字或分行，不用表演遮掩稿面缺陷。[出处](https://poets.org/text/peril-poetry-reading-page-versus-performance)

- [Blameless Incident Postmortem](https://github.com/k3rt4s/security-program-templates) — 用于严重安全事件或重大险情的事后复盘，区分检测盲点和对应整改；是安全事件文档模板，不是通用监管或审批标准。[正文](https://github.com/k3rt4s/security-program-templates/blob/main/incident-response/blameless-postmortem-template.md)

  **规则：** 写检测失效时，先区分“没有采集信号、采集了但未报警、报警了却被忽略”；针对所属情形写具体修复动作，缺少日志证据不能写成“已排除”。[出处](https://github.com/k3rt4s/security-program-templates/blob/main/incident-response/blameless-postmortem-template.md)

- [Ten simple rules for carrying out and writing meta-analyses](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1006922) — 定量系统综述的异质性检查与结果论证；以生物医学研究为例，2019 年方法建议须结合 PRISMA 2020 和具体学科规范。[正文](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1006922)

  **规则：** 研究间效应差异较大时，不要只改用随机效应模型；还应报告 I² 等异质性指标，研究数量足够时分析亚组或元回归能否解释差异，并注明未解释的部分。[出处](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1006922)

- [Writing good CL descriptions](https://github.com/google/eng-practices) — Google 的代码变更说明写作指南，以差例和实例如实交代改了什么、为什么改；可借鉴于 PR 描述，原仓库已归档且命令式标题只是其惯例。[正文](https://github.com/google/eng-practices/blob/master/review/developer/cl-descriptions.md)

  **规则：** 提交代码变更说明前，检查首行能否独立说明具体改动，并在正文写明修改原因和关键取舍；不要让“Fix bug”一类笼统标题代替说明。[出处](https://github.com/google/eng-practices/blob/master/review/developer/cl-descriptions.md)

- [Ten Simple Rules for Writing a Reply Paper](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1004536) — 公开回应已发表科研论文的反驳文章写作方法，侧重核对原论文的判据和证据；不同于返修时给审稿人的回复，案例偏生物学，仍须遵守目标期刊要求。[正文](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1004536)

  **规则：** 写公开的论文回应时，先按原作者自己的判断标准复核其结论；若原文证据与其标准矛盾，就列出标准、对应结果和推论问题，而不是另换一套评价标准。[出处](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1004536)

- [Write helpful alt text](https://developers.google.com/tech-writing/accessibility/self-study/write-alt-text) — Google 技术写作课程用同图不同语境及过短／过长的正反例指导图片替代文本；适用于网页、技术文档和图表，不等于完整的无障碍合规测试。[正文](https://developers.google.com/tech-writing/accessibility/self-study/write-alt-text)

  **规则：** 遇到复杂图表或流程图，先用简短的 alt 文本概括它的用途或主要信息，再在正文提供读者需要核对的数据表或流程说明；不要把整张图的细节塞进 alt。[出处](https://developers.google.com/tech-writing/accessibility/self-study/write-alt-text)

- [Formatting a montage sequence](https://johnaugust.com/2004/formatting-a-montage-sequence) — John August 对比同一场地与跨地点的蒙太奇写法，说明怎样用短场景压缩一段时间；适用于英语影视剧本，不是拍摄分镜或统一强制格式。[正文](https://johnaugust.com/2004/formatting-a-montage-sequence)

  **规则：** 跨地点蒙太奇先用连续短场景呈现：每次换地点只写场景标题和一两句动作；读者能看出这段快剪时，不必再加 `MONTAGE` 标记。[出处](https://johnaugust.com/2004/formatting-a-montage-sequence)

- [Productskills — PRD Writing](https://github.com/assimovt/productskills) — Tair Asim 的软件产品需求文档写作 skill，给出证据、目标和优先级的正反例；主要面向英文轻量 PRD，固定字数和 P0 数量是作者偏好。[正文](https://github.com/assimovt/productskills/blob/main/skills/prd-writing/SKILL.md)

  **规则：** 给 PRD 的每个核心成功指标配一条防止副作用的反向约束；例如提高新用户激活率时同时监测留存，不把示例数字直接当作真实目标。[出处](https://github.com/assimovt/productskills/blob/main/skills/prd-writing/SKILL.md)

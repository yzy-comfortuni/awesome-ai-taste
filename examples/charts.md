# 图表与图解：七个小练习

[返回练习入口](README.md)。根据[图表体验报告](https://github.com/yzy-comfortuni/awesome-ai-taste/issues/5)另写。全部数据为教学合成值。本页交付可复查的数值和绘图约束，不冒称已经调用远程 API、渲染七张图或完成无障碍审计。

<a id="c1"></a>
## FT Visual Vocabulary：先求偏差

输入：四区实际值 112、94、100、86，共同目标 100，单位为请求数。

预期数据：12、−6、0、−14；图形用共同零线分开正负，0 值明确标 0。坐标写“与目标 100 的差值（请求数）”。不能把没有条长当成缺数据，也不把原始值与差值混画；目标不同时另选绝对或相对缺口。

验收：算术、单位和零标签，再看渲染有无裁切。原始值不是本次测得的业务表现。

<a id="c2"></a>
## AntV：选型与远程调用分开

输入一：4—9 月数值 240、225、238、205、190、180 ms。输入二：Search、Write、Read 分别 210、165、120 ms。

预期：时间序列用折线，独立类别用零基线横条，保留 6 月回升。输入 JSON、发送请求、返回图片是三个独立阶段；本页只定义选型和数据，不发送请求。

完整技能的 POST 目的地为 `https://antv-studio.alipay.com/api/gpt-vis`，输入会外发。调用前确认数据权利、目的地和服务条款；未了解的数据保留安排不能保证。实际测试时记录 HTTP 状态、错误体、图片可访问性和逐值对照；失败时保留错误，不拿本地参考图冒充服务返回。

<a id="c3"></a>
## Scientific Visualization：重复单位不是读数数量

输入：两台设备各测三次。A 为 10、11、12 ms，B 为 14、15、16 ms。

预期记录：“2 台设备、每台 3 次重复读数”；不能直接声明 6 个独立设备样本。要画区间，先确定估计量、重复结构和合适方法；不能因模板含 errorbar 就编一个置信区间。

最低图注交代单位、观测/合成性质、独立单位和区间定义。可先画全部原始点；投稿格式、统计适用性和期刊导出是另外的验收，不因图能显示就通过。

<a id="c4"></a>
## Visual Explainer：箭头表达实际动作

输入：客户端请求 API，API 查缓存，命中值返回 API，再响应客户端。没有提供数据库或写入路径。

预期结构：`客户端 →请求→ API →查找→ 缓存 →命中值→ API →响应→ 客户端`。可分请求和响应两行，不能自动加数据库提交、重试或事务保证。

所选 v0.12.0 默认单文件 HTML + 手写内联 SVG，Mermaid 按用户请求使用。原 `mermaid-invariants` 锚点已不匹配。参见[入口勘误](../ERRATA.md#visual-explainer)。交付前检查箭头是否穿标签、端点是否正确、窄屏是否可读；静态 SVG 或另画 PNG 不能代替浏览器截图。

<a id="c5"></a>
## Baoyu Infographic：画风不能增加技术事实

输入：两种配置的合成请求数同为 100；数据库读取为 100/30；延迟为 240/180 ms。选二元比较布局，画风另定。

预期：三行两列的标签与数值一一对应，图内保留“合成数据，不代表真实性能”。如果生图自行增加缓存连线或双向箭头，逐条回查输入；没有依据就不当作技术结构使用。

本页没有调用图像后端。完整生成另需相应模型、素材许可和逐字读数核验；一次正确图片不证明多次稳定性，图片也不是精确可编辑架构。

<a id="c6"></a>
## Dashboard：统一网格不等于全部等大

输入：四区总量 392、共同目标合计 400；两个区域低于目标；最近月延迟 180 ms。

预期布局：上方三个概览，下方趋势占四列、地区缺口占两列，公共边线与间距一致。检查概览能从明细相加得到，趋势不删波动；不要把所有块硬塞成相同面积。

仓库保存的是官方替代文本，不含原 PDF 的正反例版面与图片。看视觉示例需打开官方 PDF；运行模板另需 Power BI。本页未执行模板或浏览器验收。

<a id="c7"></a>
## Chartability：把证据按项目记录

输入：两条序列仅靠红绿区分。修改：同时用圆点实线、方块虚线及直接标签区分，另提供原始数据表。

填写验收表，不统一打勾：

| 检查项 | 方法 | 可保存的证据 | 本练习状态 |
| --- | --- | --- | --- |
| 不靠颜色区分 | 灰度查看形状与线型 | 实际导出的灰度图 | 未渲染 |
| 纯色色对对比度 | sRGB 相对亮度计算 | 色值及未取整比值 | 可运行算术检查 |
| 键盘与焦点 | 浏览器实际操作 | 操作记录和焦点目标 | 未执行 |
| 屏幕阅读器 | 真实播报检查 | 工具、步骤与结果 | 未执行 |

灰度不是所有色觉模拟，存在 ARIA 不等于播报正确，单组色值通过不等于整页合规。

# 创作：保留选择，不制造统一及格线

这是根据 [issue #2](https://github.com/yzy-comfortuni/awesome-ai-taste/issues/2) 新写的虚构练习，不是原作者作品或体验者原始附件。文学判断不自动等于读者效果；实际朗读、观察、表演未做时分别记录未执行。

<a id="n1"></a>
## N1 Steering the Craft

输入：“末班车关门时，她抱着湿纸箱跑过水洼，发现箱底开始往下掉，只好用膝盖顶着，腾不出手招呼司机。”目标是意外处有一次打断，不是一律短句；本次允许新增一句呼喊。

参考稿：“末班车正在关门。她抱着湿纸箱跑过水洼；发现箱底下坠，她用膝盖顶住。腾不出手，她喊：‘等等！’”动作仍可追踪，重复的“等”承担呼喊作用。

验收：实际读两版，记录停顿、换气、误读位置再选择。仅在文本上拆句不能称听感通过。[直达第一章](https://lithub.com/a-writing-lesson-from-ursula-k-leguin/)。

<a id="n2"></a>
## N2 Fiction Writing Basics

输入人物卡：修车人缺钱，但不拿多收的 50 元；本次允许新写虚构动作。原稿：“他诚实而高尚。”

参考稿：“他又数一遍钱，抽出多的五十，夹进顾客的取车单。拨出的电话没人接，他把单子放在收款码旁。”

验收：行为支持性格，不重复宣布高尚；未接电话不能改成已经退款。编辑真实稿件时，新增情节必须符合作者授权，必要概述可保留。

<a id="n3"></a>
## N3 Ping-Pong Dialogue

输入：姐妹见面，姐姐要确认妹妹下周是否搬走；八句问候掩盖重点，允许新写场景动作。

参考稿：“妹妹谢绝了水，把整串钥匙放到桌上。‘下周就搬？’‘嗯。’姐姐把第二只杯子放回橱柜。”

验收：搬走日期还在；动作改变场景理解而非填充手势。并非每五句就应插动作，寒暄有戏剧用途时不必删。

<a id="n4"></a>
## N4 Creative Writing Skills：两张知识表

作者知道：弟弟把账本藏到锅炉房。林叶只知道抽屉空了、弟弟袖口有灰。原稿：“林叶知道弟弟昨夜藏好了账本。”

参考稿：“抽屉空着。林叶看见弟弟袖口的灰。‘你碰过这里？’”把信息标成可观察/推测/作者秘密；正文不出现未获知的藏匿地点。

验收：不让大纲真相渗进限知视角。采用这一检查不代表采用上游标点偏好、训练解释或多代理流程。

<a id="n5"></a>
## N5 Chinese Novelist：遮标签而非删标签

输入：仓管先核编号，新人报告观察。两人都说“我认为应该检查箱子”。

参考对白：“先念箱号，别拆封。”“十七号，底下湿了。我垫件外套行吗？”

验收：遮住标签后按人物目标回填；“好”可能谁都能说，不硬加口头禅。正式稿仍可留标签，不执行固定句长及章末钩子配额；作者自查不等于独立盲测。

<a id="po1"></a>
## P1 Integrity of the Line：只改换行

输入字序：“我把／毛衣放回／箱子／箱盖夹住／一截／袖子”。斜杠表示原换行。

参考二行版：“我把毛衣放回箱子／箱盖夹住一截袖子”。只取消部分换行，不同时改词；逐处说明失去或获得的停顿。

验收：去换行后字序必须相同。如果目的正是失语或犹豫，原版可能更合适；不按行数给诗评分，不要求押韵。

<a id="po2"></a>
## P2 Image in Poetry：让观察者参与

虚构观察笔记：蓝伞、弯骨、红线把手、已晾干、借伞人未到。不是模型的亲身见闻。

参考稿：“蓝伞晾干了／我把红线缠过的把手转向门口／让你伸手就能拿走。”

验收：细节进入等待关系，不靠附加“我非常想你”解释全部情绪。完整户外观察活动和真实读者反应另记未执行。

<a id="po3"></a>
## P3 Flying Revision’s Flag：分开重排与新增

输入：“渡船回来／我等一个未定归期的人／岸灯亮了”。

先保留原稿；重排稿：“岸灯亮了／渡船回来／／我等一个未定归期的人”。新增稿再加“船舱的空座也被灯照着”，明确这是新写材料。

验收：比较灯的位置和新空座是否过早暗示结局；保留多个版本，不默认新增稿更好。分节练习不冒充英语格律或长期搁置后的判断。

<a id="s1"></a>
## S1 How to Write a Scene

输入：紧凑悬疑片，A 交钥匙并说明八点封楼，B 无关问天气，C 用钥匙取册子。试删 B。

参考输出：A→C，钥匙来源、期限、目的地都在，无须补洞台词。另记损失：少了日常气氛。

验收：按“紧凑悬疑”目标决定是否接受损失；关系戏或日常叙事不能只凭不推进情节就删场。没有拍摄，不记可演性通过。

<a id="s2"></a>
## S2 How to Write Dialogue

输入：影院十二点断电，妹妹坐十一点五十的车，来人想多等十分钟看家庭影片；本次允许新写动作。

参考稿：“我妹妹的车十一点五十到，再等十分钟，就能一起看这卷家庭影片。”“十二点断电，只能放这一卷。”放映员把手从开关上收回。

验收：双方争取的反应清楚，时间与片子还在；不能凭润色新增过去失约的事实。心理活动不能代替可拍动作，真人表演另测。

<a id="s3"></a>
## S3 Writing Fight Scenes

输入：双方争档案箱，原件易碎，推车临门；主角优先护原件。

参考稿：争箱使箱盖弹开，纸页落向车轮；主角松手护纸，让对方抱箱离开。结局由目标和场地决定，不用“主角占上风”概括一切。

验收：去掉纸页与推车后动作不能原样成立。这里只写叙事取舍；空间调度、表演与现场安全仍需相应专业人员。

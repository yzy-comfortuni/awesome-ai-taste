# 专利与论文：先把依据放在旁边

以下均为新写的虚构教学材料，不是申请文件、真实研究或法律意见。根据 [issue #1](https://github.com/yzy-comfortuni/awesome-ai-taste/issues/1) 整理。正式专利判断须结合目标法域、完整材料和专业审查；例子的文字对应不能证明充分公开。

<a id="p1"></a>
## P1 WIPO：支持对照表

输入事实：夹具有底板、导槽、移动夹板和螺杆；螺杆驱动移动夹板沿导槽移动。材料仅描述夹持 2–8 mm 矩形纸板。待查句：“任意驱动件可使各种材料自动定位。”

| 权项特征 | 已知依据 | 推导条件 | 待询问事实 |
| --- | --- | --- | --- |
| 螺杆移动夹板 | 已给结构 | 按已给连接关系说明 | 无 |
| 任意驱动件 | 只给螺杆 | 不能仅换同义词扩大 | 是否有其他既有方案资料 |
| 自动定位各种材料 | 未给 | 尚不能作这种表述 | 定位结构、对象范围与效果依据 |

参考输出：“螺杆使移动夹板沿导槽移动。”保留“2–8 mm 是否属于必要限定”的问题，不现场补第二实施例，也不将未找到逐字对应直接当法律结论。

精确阅读位置：[第六单元第 10 节](https://www.wipo.int/edocs/pubdocs/zh/wipo-pub-867-23-zh-wipo-patent-drafting-manual.pdf#page=108)，印刷页 107–108，对应 PDF 页 108–109。

<a id="p2"></a>
## P2 EPO：展开后再改引用

输入：C1＝底座＋臂；C2 引用 C1，臂为聚合物；C3 引用 C2，臂为铝；C4 引用 C3，端部有圆角。事实包明确聚合物与铝是替代方案。

参考输出：旧 C3＝底座＋臂＋聚合物＋铝；旧 C4 还继承这一冲突。拟将 C3 改为引用 C1，新 C3＝底座＋铝臂；新 C4＝底座＋铝臂＋圆角。

验收：同时写出发现的冲突和修改移除了什么限定。没有“替代方案”的输入依据就先询问，不能自动改引用。方法对应 [EPO 2026 F-IV 3.4](https://www.epo.org/en/legal/guidelines-epc/2026/f_iv_3_4.html)，不覆盖全部多重引用问题。

<a id="p3"></a>
## P3 MPEP：真歧义与非机械错误

输入：“推动滑块的杆、锁住滑块的杆和球体。所述杆连接滑块。球体的外表面有刻线。”图意已明确连接的是推动杆。

参考输出：将两根杆分别命名为驱动杆、锁止杆；写“驱动杆连接滑块”。指代结果记录为“杆：多候选，依图意消歧；球体：唯一对应；外表面：需语义判断，不因没有单独引入而机械报错”。

验收：没有图意时不猜哪根杆。参照 [MPEP 2173.05(e), R-01.2024](https://www.uspto.gov/web/offices/pac/mpep/s2173.html)；本练习不是清楚性审查结果。

<a id="p4"></a>
## P4 中国专利.skill：最小三件套

输入事实：连续三个读数取等权均值，m≥5 输出 1，否则输出 0。权项写“处理器”，说明书写“计算模块”，图写“滤波器”，但材料没有滤波步骤。

参考输出：把同一计算部件统一称为“处理器”。流程图只画“S1 取三个读数 → S2 计算均值 → S3 按阈值判定”，不增加三块硬件或滤波步骤。说明书明确 m=(x1+x2+x3)/3 和 m≥5；箭头分别写“三个读数”“均值 m”。

| 权项内容 | 说明书依据 | 图示 |
| --- | --- | --- |
| 三个读数 | 输入段 | S1、第一条箭头 |
| 等权均值 | 公式段 | S2 |
| m≥5 判定 | 判定段及边界例 | S3 |

验收：2、4、9 得 m=5，输出 1。仅做人工对照；上游脚本、YAML 和 Word 流程另需完整工程，名称一致不等于法律上的充分公开。

<a id="p5"></a>
## P5 CN Patent Disclosure：中间量不变成虚构风险

输入：m=(x1+x2+x3)/3，r=max(0,m−6)，r>0 时提示。短版参考：“先计算三点均值 m，再计算均值超过 6 的幅度 r；仅当 r>0 时提示。”

完整版再加：r=0 合并了低于和等于阈值两种情况；输入 6、6、6 输出不提示，7、7、7 输出提示。若材料未给领域解释，不能把 r 称作故障概率。简单步骤允许合并成一段，不必硬拆六小节。

<a id="a1"></a>
## A1 Structuring Papers：保留反向结果

输入：四组合成错误计数，每组 100 例，基线/候选为 12/4、8/7、3/3、4/5。原主张：“所有场景均显著改善。”

参考输出：“本组合成计数的减少主要来自第一种情景；合计由 27 降至 19，第三组不变，第四组变差。”提纲顺序为证据性质、主要变化、反例、局限，不按实验日期排列。

验收：保留 4→5 和人工设定性质；没有统计检验不得写显著，没有采样与外部验证不得写普遍有效。

<a id="a2"></a>
## A2 Literature Reviews：空白格不是无效

输入：虚构材料 L1 短任务即时错误少、未测延迟；L2 长任务即时无差异；L3 仅熟练者、即时错误少、一周后无差异。

参考矩阵：L1＝短/人群未说明/即时少/延迟未测；L2＝长/人群未说明/即时同/延迟未测；L3＝任务时长未说明/熟练者/即时少/一周同。提纲：“短任务的即时表现不能外推到长任务或长期能力；初学者证据不足。”

验收：同一材料可用于不同主题；未测不等于无效，设计不同不能直接合并为因果解释。此矩阵不替代系统综述的检索和质量评价。

<a id="a3"></a>
## A3 Response to Reviewers：把回复与改稿配对

输入意见 R1：“Please define n=4 and provide external validation.”事实：四个数是人工设定的教学情景，没有新增实验。V1：“n=4; effective in real-world use.”

参考 V2-M：“The four settings are manually specified teaching scenarios, not independent experimental replicates.”

参考 V2-L：“No external validation was performed. These synthetic counts do not establish real-world effectiveness.”

| 回应 | 状态 | 可核位置与内容 |
| --- | --- | --- |
| R1a | 已完成改稿 | V2-M，如上逐字引用 |
| R1b | 已收窄主张；新增实验未完成 | V2-L，如上逐字引用 |

参考回复：“We clarified the four settings in V2-M and removed the real-world claim in V2-L. We have not performed an additional validation study.”保留 R1 全文，分别回应两个问题；不造页码、数据或“已补实验”。

<a id="a4"></a>
## A4 Scientific Software Papers：教程移走，方法留下

输入：仅有按 ID 去重并记录原因的设计，无实现、版本、测试或 DOI。草稿夹着 Upload/Clean/Download 点击说明并宣称高性能。

参考输出：正文保留 ID 去重、输出原因和“同 ID 不同内容尚无冲突规则”；点击步骤进入“拟议界面流程”，标未实现。版本、代码 URL、归档 DOI 均写未提供，不能写“见最新文档”后造链接。

验收：移动的是使用教学，不是算法、关键参数或复现依据；结构改善不能把设计草案变成已验证软件。

<a id="a5"></a>
## A5 Reviewing Academic Papers：每个批评有落点

输入：S1 写“适合所有输入”；R2 有稀疏组错误 4→5；F1 只有“错误率”但没有分母；T1 写 methd。

参考评审：主要问题＝S1 与 R2 稀疏组矛盾，应收窄范围并保留反例；次要问题＝F1 补计数/分母与单位；笔误＝T1 改 method。接收建议另给编辑，不混入给作者的主要问题。

验收：每条意见有“位置—证据冲突—可接受修复”；不笼统要求无限补实验，也不自动要求公开受隐私限制的数据。

<a id="a6"></a>
## A6 图形摘要：两个箭头不能含混

输入（合成教学情景）：研究工作包括采集、预处理和预测三个先后步骤；另一处展示假设指标由 60 上升至 70。没有提供因果证据、统计检验或现实数据。

参考设计：步骤之间用细实线箭头表示流程；数值旁用形状明显不同的粗上箭头表示“60→70（合成示例）”。在图注中分别解释“流程顺序”和“指标上升”，不让同一种符号兼任两种含义。

验收：逐个指出每类箭头的含义，保留数值、合成性质和缺少因果证据的限制；不能把 60→70 写成显著改善。本练习只提供设计检验目标，没有渲染图形、进行期刊格式验证或真人读图测试。

# 界面：先区分源码检查与真实使用

根据 [issue #3](https://github.com/yzy-comfortuni/awesome-ai-taste/issues/3) 新写。案例是虚构工具借用站。[离线页面](review-demo.html)包含空状态、表单和对比度练习；其余条目给出修改规格，不冒充已渲染截图。浏览器操作、屏幕阅读器和真机体验需分别执行。

<a id="u1"></a>
## U1 UI Skills

输入：空清单只写“暂无数据”。参考输出：“还没选择工具”＋一个“查看可借工具”链接，实际目标为清单区域。

验收：一个主操作且目标存在；再用浏览器点击。读取 React/Tailwind 完整技能和零依赖空状态练习是两件事。

<a id="u2"></a>
## U2 Frontend Design

输入：并列用途“装搁板、修家具、擦高窗”前有装饰性 01/02/03。

参考输出：删编号，不删用途；真正有次序的“挑选→领取→归还”仍保留编号。验收比较内容与关系，不能将删装饰计成自动美感通过。

<a id="u3"></a>
## U3 Impeccable

输入：“释放无限可能”＋无关圆点，替换品牌后可用于任何行业。

参考输出：用工具架及梯子借出后的空位表达工具借用；标题“只用一次，不必买一套”。验收：视觉对象和入口与任务对应；素材真实性和完整 CLI/双评估另外验证。

<a id="u4"></a>
## U4 Taste Skill

输入：居民先找可借工具和领取时间，首页却有循环大标题动画。

参考输出：选择低动效的入口页；把工具、时间、地点放前面，取消循环装饰。旋钮只是本案选择，数字本身不生成版式；不把此技能套到仪表盘、数据表或多步产品流程。

<a id="u5"></a>
## U5 Web Interface Guidelines

输入：工具名为空，天数为 8，只在页顶报错。参考输出：字段旁分别显示原因；提交后焦点到工具名，修正后到天数。合法天数为 1–7 整数，成功只说本地检查通过。

验收：空值、0、8、小数、非数字、首尾空白；用真实 Tab/Enter 和焦点检查，不以 stub 代替。保留用户缩放，不复制 `maximum-scale=1`；参考 [勘误](../ERRATA.md#zoom)。

<a id="u6"></a>
## U6 Interfaces

输入：等距嵌套，内圆角 8 px，内边距 12 px，边框 1 px，外圆角误写 8 px。

参考输出：外圆角为 21 px。验收分别核算等式和实际曲线；内边距超过 24 px 或不对称时，不机械套此公式。

<a id="u7"></a>
## U7 Emil Design Engineering

输入：每次筛选都播放 700 ms 入场。参考输出：结果即时更新，不重复播放；保留选中样式、`aria-pressed` 与结果数。

验收：连续切换后数据和状态正确，再测键盘、触控、中断和实际帧率。取消动效不等于取消反馈，也不是所有页面都不准动。

<a id="u8"></a>
## U8 Visual Design Foundations

输入：同级卡片各自取字号和间距；普通 18 CSS px 的灰字对比度为 3.2:1。

参考输出：同类组件引用同一组变量；灰字不能因大于 18 px 就放宽到 3:1，应达到一般文字门槛或按实际字号/字重重新判断。24 CSS px 普通字与 14 pt 粗体的门槛另算。

验收：共享变量检查、纯色色对计算、实际渲染分开；4.499:1 不向上取整。见 [单位勘误与官方依据](../ERRATA.md#contrast)。
